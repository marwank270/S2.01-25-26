## Exercice complémentaire

### Phase 1
* Vous travaillez à partir d'un fichier HTML de départ (step0). Vous ne touchez pas au "body" de la page en aucun cas.
* Vous choisissez 2 images de votre choix sur internet que vous stockerez dans un dossier images de votre projet.
* Dans un premier temps vous devez affichez ces 2 images dans la page entre le titre et le paragraphe donc juste après (after) le titre.
Ces images seront affichées en 300x300 pixels avec pour message alternatif ('Pb chargement').


### Phase 2
* Dans un second temps, on veut que lorsque l'utilisateur double-clique sur l'une des 2 images ca les échange.

### Phase 3
* Dans un troisième temps, on veut que ca marche 3 fois (au total) et pas plus. L'effet double-clique disparait. Le paragraphe en dessous des images est supprimé (remove). Et le titre doit désormais afficher '2 images qui permutaient'.


### Phase 4
* Dans un quatrième, temps ajoutez un peu de style via JS au titre (fond jaune, encre rouge) au paragraphe (police 1.5rem), et par exemple ajouter une bordure rouge de 5px autour des images. 
* afficher la deuxième image complètement sur la droite. Vous avez toute liberté pour le style à ajouter mais faites le bien via JS.
* Enfin factorisez (si ce n'est déjà fait) tout ce que pouvez notamment le code de création des images sous la forme d'une fonction créerImage.
